# Pipoca5

Projeto de jogos 2D para M5Stack Tab5.

- O usuário autorizou a implementação de `docs/REQUISITOS.md`. Desenvolver
  incrementalmente com código funcional, modular e testes de regras.
- Trabalhar nesta pasta; os outros projetos são apenas referências.
- Organizar hardware nos módulos `main/display`, `main/input`, `main/audio`, interface em `main/ui`, jogos em
  `main/games`, recursos em `assets`, documentação em `docs` e testes em `tests`.
- Priorizar o binário da aplicação para OTA. A especificação atual também
  autoriza gerar o pacote separado de USB, sem gravá-lo.
  Não executar flash, monitor, erase-flash ou abrir a serial sem pedido explícito.
- Não publicar no GitHub sem solicitação do usuário.
- Código original sob MIT; preservar os avisos dos componentes de terceiros.
- Não copiar implementações GPL do Tab5Meshtastic para o código original.
- Não alegar 60 FPS, funcionamento do teclado ou áudio sem medição no Tab5.
